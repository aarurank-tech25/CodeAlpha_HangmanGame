# 🎮 Hangman Arena

**A feature-rich, web-based Hangman gaming platform built with Python and Flask.**

🌐 **Live Website:** https://hangman-arena.onrender.com  
📂 **GitHub Repository:** https://github.com/aarurank-tech25/CodeAlpha_HangmanGame

## 📌 About the Project

Hangman Arena is an interactive web-based word-guessing game where players guess hidden words, earn experience points, unlock achievements, and compete through multiplayer gameplay.

The project started as a basic Hangman game and was expanded into a complete gaming platform with user accounts, game history, daily challenges, rankings, and persistent database storage.

## ✨ Features

- **User Authentication:** Register, login, and manage player accounts.
- **Hangman Gameplay:** Guess hidden words and track wins and losses.
- **XP and Levels:** Earn experience points through gameplay.
- **Game History:** Review previous game results.
- **Badges and Achievements:** Unlock rewards through gameplay.
- **Daily Challenge:** Play daily word challenges.
- **Multiplayer:** Play turn-based games using room codes.
- **Leaderboards:** Compare player rankings.
- **Player Profile:** View player progress and statistics.

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/aarurank-tech25/CodeAlpha_HangmanGame.git
   ```

2. Open the project folder:

   ```bash
   cd CodeAlpha_HangmanGame
   ```

3. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Configure the required environment variables, including `SECRET_KEY`. For PostgreSQL mode, configure `DATABASE_URL` with your own database connection string.

5. Start the application:

   ```bash
   python app.py
   ```

6. Open your browser:

   http://127.0.0.1:5000

## ☁️ Deployment

The application is deployed using Render, with Neon PostgreSQL providing cloud database storage.
