# 🎮 Hangman Arena

A feature-rich, web-based Hangman gaming platform built using Python and Flask.

🌐 **Live Website:** https://hangman-arena.onrender.com

💻 **GitHub Repository:** https://github.com/aarurank-tech25/CodeAlpha_HangmanGame

## 📌 About the Project

Hangman Arena is an interactive word-guessing game where players guess hidden words, earn experience points, unlock achievements, and compete with other players.

## ✨ Features

- User Registration and Login
- Interactive Hangman Gameplay
- XP and Level System
- Game History
- Badges and Achievements
- Daily Challenges
- Multiplayer Gaming
- Global Leaderboard
- Player Profiles
- PostgreSQL Database Integration

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- PostgreSQL
- Neon
- Render
- Git and GitHub

## 💻 Installation

1. Clone the repository:

   `git clone https://github.com/aarurank-tech25/CodeAlpha_HangmanGame.git`

2. Open the project folder.

3. Install dependencies:

   `python -m pip install -r requirements.txt`

4. Configure the required environment variables.

5. Run the application:

   `python app.py`

6. Open http://127.0.0.1:5000 in your browser.

## ☁️ Deployment

The application is deployed using Render, with Neon PostgreSQL for cloud database storage.
